# Repo City

- Develop in this directory. Do not modify the original courier or Sloposcope projects.
- Do not create branches or worktrees without the user's explicit confirmation.
- Keep repository identity, source snapshots, comparisons and private drafts independent of world sets.
- The active world set is the city. Library and bug-world concepts are alternatives, not decorations to combine.
- Reuse copied code where practical. Record its source revision and explain local adaptations.
- Never write gameplay edits to the inspected repository. Export only on an explicit in-app action.
- Keep unsupported extraction and unverified behavior visibly distinct from measured facts.
- Keep interface edges square. Use rounded corners on controls, panels, and dialogs only when the user explicitly requests them.
- Run the focused Rust checks and inspect the native application after visual changes.
- A new rendering or locomotion metaphor belongs in a world-set presentation adapter.
